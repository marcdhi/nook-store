What we'd like from you

  1. Reproduce each issue, find the root cause in the code, and explain the fix you would ship. Think out loud.
  2. Prioritise. You probably won't get through everything, so tell us what you'd fix first and why.
  3. There are more problems than the tickets. Point out anything else you notice (correctness, security, UX, maintainability).

How to work on it

You only have the browser, and that's enough. Everything is unminified plain JavaScript.

  • Open DevTools (F12 / Cmd+Opt+I). The code is in Sources: app.js (the UI) and api.js (a fake backend with simulated network latency — treat it as a server you don't own).
  • Use breakpoints, the Console, the Elements → Event Listeners panel, and Network throttling, whatever you'd normally use.
  • Want to try a fix? In Chrome: Sources → Overrides → "Select folder for overrides" → allow. Then edit app.js in Sources, save (Ctrl/Cmd+S) and reload. Your edited copy loads instead of the server's.
  • The cart is stored in localStorage. Application → Local Storage → clear it if you want a fresh start.
